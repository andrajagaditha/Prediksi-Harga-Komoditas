# 🌶️ Prediksi Harga Komoditas Pangan

Aplikasi berbasis web menggunakan **Streamlit** untuk memantau tren harga cabai rawit merah di Kota Semarang.

## Fitur
- Grafik tren harga interaktif.
- Metrik kenaikan/penurunan harga dibanding minggu lalu.

## Cara Menjalankan di Lokal
1. Install library: `pip install -r requirements.txt`
2. Jalankan aplikasi: `streamlit run app.py`
